# WA Big Batteries Project

This repository supports research into resource adequacy metrics for large-scale battery energy storage in Western Australia's South West Interconnected System (SWIS). This work builds data pipelines and analysis over public AEMO WA market data (facility SCADA, case input, and dispatch solution) to characterise how batteries actually behave under system stress, and develops a short-horizon adequacy metric conditioned on current system state rather than averaged over simulated futures. The project is conducted at the Australian National University in partnership with AEMO WA, with funding from AR-PST Project.
